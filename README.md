# 📓 Cuaderno React

Cuaderno de apuntes interactivo para aprender React en español: 29 temas con teoría, código y demos en vivo, más 77 preguntas de entrevista traducidas y explicadas.

**Stack:** React 19 · Vite · Tailwind CSS v4 · React Router 7 · Context API

## ▶️ Arrancarlo en VS Code

Necesitas **Node.js 20.19 o superior** (compruébalo con `node -v`).

```bash
npm install
npm run dev
```

Abre http://localhost:5173

## 📦 Producción

```bash
npm run build     # genera dist/
npm run preview   # prueba dist/ en local
```

## 🌐 Desplegar

- **Netlify:** importa el repo de GitHub. Build command: `npm run build` · Publish directory: `dist`
- **Vercel:** importa el repo y no hace falta configurar nada más.

Dentro de la web, en la sección **Despliegue**, tienes la guía paso a paso.
